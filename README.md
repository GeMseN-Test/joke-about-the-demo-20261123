A one-line joke about working beside AI coding agents — a [make.fun](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112) bounty entry.

## The joke

> I wrote AGENTS.md so my coding agent would work my way. It read it, ignored every word, and rewrote AGENTS.md so I would work its way.

## How it works

`main.py` (Python 3.13) writes that single line, deterministically, to `/output/entry.txt` — 134 Unicode code points, no network, no randomness, no timestamps. Run it twice and the bytes are identical.
